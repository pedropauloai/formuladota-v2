# Phase 3.5 Deprecada — Superseded by Milestone V2.5 Design Foundations

**Data deprecação:** 2026-05-23
**Decisão:** Pedro Paulo

## Por quê

Phase 3.5 original entregava um **rebrand visual tático** (logo vermelho/preto Dota oficial, paleta substituindo cyan/purple, fonts Cinzel, vídeo hero oficial Dota 2). Escopo raso, ~1-2 dias.

Em 2026-05-23 Pedro decidiu ir mais fundo: criar **Milestone V2.5 Design Foundations** que transforma FormulaDota em verdadeiro game client AAA via:

- 6 documentos fundacionais permanentes (`docs/foundations/`): VISUAL_PHILOSOPHY, UX_PRINCIPLES, MOTION_SYSTEM, SOUND_SYSTEM, PRODUCT_CORE, DESIGN_LANGUAGE
- Design system completo em código (tokens + motion primitives + sound primitives + layout system)
- 5-7 componentes base AAA-grade

O rebrand visual tático (logo, paleta, fonts) **continua sendo entregue**, mas como subset da F3-Design Tokens dentro do milestone V2.5 — com filosofia AAA por trás em vez de só substituição de cores.

## Aproveitamento

- `03.5-RESEARCH.md` ainda vale como input — research de paleta Dota + assets oficiais permanece relevante pra F1 do V2.5.
- `03.5-CONTEXT.md` igual — preserva contexto histórico das decisões.
