### D-01: Paleta cores oficial Dota
- **Background primário:** `#000000` puro (igual home oficial Dota — confirmado via Playwright)
- **Background secondary** (cards, sections elevadas): `#0A0A0A` ou `#111111` (sutil elevação)

- **Vermelho hover/dark:** `#7F1D1D` (red-900) pra estados hover de CTAs vermelhos
- **Texto principal:** `#F5F5F5` (off-white com warmth, igual Dota — não puro `#FFFFFF`)

### D-02: Tipografia (Google Fonts via next/font/google)
- **Cinzel** — `weight: ['600', '700', '900']`, `variable: --font-display` — headings de impacto (h1, h2 hero), CAPS por padrão. Replaces Space Grotesk como display font.
- **Marcellus** — `weight: ['400']`, `variable: --font-serif` — subheadings, quotes, taglines (estilo "Uma obra-prima moderna multijogadora")
- **Inter** — `weight: ['400', '500', '600', '700']`, `variable: --font-sans` — body text, nav, buttons, forms. Replaces default sans-serif. Pesos modernos.
- **JetBrains Mono REMOVIDO** — sem mono em UI atual (usar `font-mono` apenas em código se necessário, mas limitar)
- Tokens em `src/app/layout.tsx` exportados como CSS variables, `tailwind.config.ts` mapeia `font-display` → `var(--font-display)`, `font-serif` → `var(--font-serif)`, `font-sans` → `var(--font-sans)`

### HeroVideo component pattern
```tsx
"use client";
const DEFAULT_HOMEPAGE_VIDEO = "https://cdn.steamstatic.com/apps/dota2/videos/dota_react/homepage/dota_montage_webm.webm";
const DEFAULT_HOMEPAGE_VIDEO_MP4 = "https://cdn.steamstatic.com/apps/dota2/videos/dota_react/homepage/dota_montage_02.mp4";

export function HeroVideo({ heroSlug, src, className }: HeroVideoProps) {
  const webm = src ?? (heroSlug
    ? `https://cdn.akamai.steamstatic.com/apps/dota2/videos/dota_react/heroes/renders/${heroSlug}.webm`
    : DEFAULT_HOMEPAGE_VIDEO);
  const mp4 = src ?? DEFAULT_HOMEPAGE_VIDEO_MP4;
  return (
    <video autoPlay loop muted playsInline className={className}>
      <source src={webm} type="video/webm" />
      <source src={mp4} type="video/mp4" />
    </video>
  );
}
```
